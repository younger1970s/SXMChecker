SiriusXM Radio ID Checker

Captures of the running app - the same window dist/RadioIDChecker.exe opens, first as it starts, then with the Settings panel open on a dark theme. The result on screen is sample data (DEMO0001 is fictional): a live check needs a real Radio ID.

Buttons

  • Check Subscription - looks the Radio ID up on the US/Canada care endpoints and reports the plan, the trial/demo flag, the dates and the days left.
  • Request Signal View Web - opens SiriusXM's official refresh page in your browser and copies the Radio ID to the clipboard, ready to paste into the form. The app drives no browser of its own.
  • Settings - opens the panel described below; the gear next to it follows the theme's accent.
  • Clear / Copy result - reset the form, or copy the shown result to the clipboard.

Settings

The Settings button opens a panel that changes the look of the window while you use it: every choice is applied as you pick it, and remembered in %APPDATA%\SXMChecker\settings.json, so there is no OK button. Reset to defaults puts everything back.

  • Check result font / size - the Radio ID field, the result box and the Recent menu. Monospaced faces (Consolas, Cascadia Mono, Lucida Console, Courier New) keep the result columns aligned; the proportional faces are there if you prefer them.
  • Interface font / size - the labels, buttons and headings.
  • Box size - how many rows and characters the result box keeps, so the window can be sized for the output you expect.
  • Theme - Light, Dark, Midnight, Slate, High contrast and Amber CRT. Each theme carries its own status colours, so the banner stays readable on black as well as on white.
  • Accent - tints the heading, the progress bar and the focus ring. Picking a theme adopts that theme's accent.

Recent

Recent lists the Radio IDs you have checked or requested a signal for, newest first, each with the expiry date the last check found; pick one to drop it straight into the field. The list is remembered between runs in %APPDATA%\SXMChecker\history.json (up to 15 IDs), and Clear history at the bottom of the menu removes it - including the file's contents.

The Radio ID field is sized for a VIN (17 characters, the longest ID accepted), and Recent takes the width that frees up. The menu itself is monospaced and pads the ID to that same width, so the expiries line up in one column; until a check has produced a date the entry reads Unknown:

DEMO0001          - expires 2099-10-01
TEST0002          - expires 2027-06-30
SAMPLE03          - Unknown

Market order

Auto (US, then Canada) is the default and matches the dealer CLI; Canada first flips the order, and US only / Canada only pin a single market. The choice also decides which refresh page Request Signal View Web opens.
